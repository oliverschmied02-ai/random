# Our Story

Ein persönliches, stilisiertes 3D-Story-Spiel in Godot 4 — ein Geburtstagsgeschenk,
das wichtige Momente unserer Beziehung als spielbare Szenen nacherzählt.

## Aktueller Umfang

**Kapitel 1 — Berlin** (COVID-Zeit, Alexanderplatz-Spaziergang, Minispiel "Vaccination Darts").

Weitere Kapitel sind konzeptionell vorgesehen, werden aber bewusst noch nicht gebaut.

## Status

Repository vorbereitet. Das Godot-Projekt existiert noch nicht — Stage 1 (Foundation:
Projektstruktur, Input-Mapping, Third-Person-Movement, Kamera, Testumgebung) steht als
nächstes an.

## Technologie

* Godot 4
* GDScript
* Git

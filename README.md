# Repository Connection

This repository is connected to: https://github.com/oliverschmied02-ai/Zwangsversteigerungen

## Remote Configuration

The upstream repository has been configured as a remote:

```bash
git remote add upstream https://github.com/oliverschmied02-ai/Zwangsversteigerungen.git
```

To sync with the upstream repository:

```bash
git fetch upstream
git merge upstream/main
```
